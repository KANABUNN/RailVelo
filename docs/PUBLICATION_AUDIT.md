# 公開前監査

確認日: 2026-10-21。対象は公開候補の作業ファイル、到達可能なGit全履歴、同梱SQLite 2個、原典ZIP/PDF/HTML。

## 結果

- 秘密鍵、既知のGitHub/AWS/Google/OpenAI/Slackトークン形式、具体的な認証値の代入、認証情報を含むURL、署名資料を検査し、検出なし。
- 初回コミットの作者・コミッターをGitHubのnoreplyアドレスへ変更。検証ログのユーザーフォルダー入り絶対パスも履歴から除去した。
- 書換前のコミットが元GitHubリポジトリに残存することを確認したため、元リポジトリは別名の非公開バックアップとして保管し、新規リポジトリへ整理済み履歴だけを送信した。新リポジトリから書換前のコミットを取得できないことを確認した。
- `data/railway.sqlite` と `vendor/n02/output/rail_jrkyushu.sqlite` の整合性は正常。旧DBの `rides` / `gps_samples` / `match_results` / `station_events` は全て0行。個人の実走履歴を同梱していない。
- `fixtures/` は固定seedと公開線形に基づく合成観測。生成元は `scripts/generate_fixtures.py`、用途は `fixtures/README.md` に記録。
- 原典ZIP/PDF/HTMLの5ファイルは取得記録のSHA-256と一致。ZIPの24エントリーにも署名資料・秘密情報用ファイル名はなく、展開内容の検査でも認証情報は検出なし。
- 原典CC HTMLの連絡先メールはCreative Commonsの公開連絡先であり、個人の認証情報ではない。
- Appleのアカウント画面に表示される個人情報、Team情報、証明書やAPI秘密鍵をソース・証跡へ転記していない。

## 今後の扱い

再実行は `python scripts/audit_publication.py`。検出値自体をログへ出さず、分類・ファイル・行・履歴blobだけを報告する。現ファイルと全履歴の両方を対象にする。生成されたローカル履歴、実GPS、CSV、鍵・証明書、環境変数ファイルはGitへ追加しない。

公開設定は所有者が変更する。非公開バックアップは公開対象に含めない。公開後も署名情報はGitHub Actions Secretsなどの専用保管先で管理し、通常のファイル、ログ、ビルド成果物に含めない。

これはパターン検出と出典・内容の手動確認を組み合わせた監査であり、任意の形式で埋め込まれた全ての秘密が存在しないことの数学的保証ではない。変更後は追加差分と履歴を再検査する。
