# Simulator UI検証 — v0.5

対象：iPhone 16 Simulator、同梱の合成GPSリプレイ。実GPSや個人アカウントは使用しない。XCUITestは実アプリ・Core Locationと共通の入力経路・推定・SQLite・CSV共有画面を使用する。

下表は`52464c9`の試験stepで確認した結果。時刻ラベルを短縮する追加修正後の最終版は再試験待ちである。

| 検証項目 | 方法 | 結果 |
| --- | --- | --- |
| 速度グラフの実描画 | 画面をスクロールし、グラフ領域の実画像内にデータ色の画素を確認 | 点の画素検査は成功。先行版で目視確認。時刻目盛の最終目視は再試験待ち |
| 60秒・5分・全体 | 3ボタンを操作し、選択状態・観測件数・実描画を検査 | 3期間の切替・点描画は成功 |
| 記録開始・一時停止・再開・終了 | 実リプレイを操作し、非同期保存の完了を待つ | 一連の操作と永続化待機が成功 |
| 履歴表示・保護・削除 | 一時停止中は削除不可、終了した今回作成の合成履歴だけ削除 | 表示・保護・対象限定削除の操作が成功 |
| CSV | SQLiteから生成されたCSVのiOS共有画面を表示、送信せず閉じる | ネイティブ共有画面の表示とキャンセルが成功。実機のFiles保存は別試験 |
| 明暗表示・大きい文字 | 実際のSimulator設定とAccessibility Audit | Light/Dark・拡大文字の指定監査とスクロールが成功 |
| VoiceOver | 基本ラベルと説明は自動検査。音声・フォーカス移動は本人のiPhoneで確認 | 実際の読み上げは未実施 |

XCUITestの各操作画像は`ui-light.xcresult` / `ui-dark.xcresult`に保存する。公開できるのは、この使い捨てSimulator上の合成データによる検証成果物だけ。ユーザーが実機で記録したファイルはCIへ送らない。

## 実行と目視の証跡

`52464c9f58d1b2435a425a32dad7c6251699e066`の[run 39529981900](https://github.com/KANABUNN/RailVelo/actions/runs/39529981900)で、両ビルド・smoke・中断復旧、Lightの全操作/LargeText、Darkの監査/スクロール、添付PNGの書き出しが成功した。終了確認の重複要素への対応と、進捗の44pt以上の読み上げ要素を実際に再試験した結果である。続いてX軸を24時間の`HH:mm:ss`、通常3目盛/拡大文字2目盛、両端を内側へ揃える表示へ修正し、最終版を再検証する。

`512ea0335481719a13830c2fc87477a421c58a25`の[run 39528724495](https://github.com/KANABUNN/RailVelo/actions/runs/39528724495)で、両アプリビルド・smoke・中断復旧、文字拡大監査が成功した。全操作試験は再開後の終了確認で、iOSの親子Button重複を単一要素として検索したため失敗した。Dark監査は駅間進捗の細いProgressIndicatorの領域不足で失敗した。確認ボタンを明示IDで操作し、進捗は割合・次駅距離を含む44pt以上の単一読み上げ要素へ修正した。監査項目の除外で成功扱いにはしていない。

同runの`ios-build-evidence`（artifact `12315121426`、SHA-256 `1c20f1d5e427e92eb1daad200dc73a16b4e37b60d118e1bae12fa918509ff653`）を取得・ハッシュ照合し、60秒・5分・全体と大きい文字の実画像を目視した。PNGは`ui-light-screenshots/manifest.json`等で添付名と照合できる。点描画と切替は確認したが、時刻ラベルが重なっていたため表記と目盛数を修正する。成果物は公開先で1日保持、手元ではGit除外対象の`artifacts/`に保存する。

## 合格へ拡張しない範囲

同梱fixtureの観測間隔は25秒で、連続観測として結ぶ閾値を超えるため、今回のグラフは点として描画される。点の実画素を確認した結果を、短い取得間隔での連続線・実GPS・列車での実走の合格へ拡張しない。連続線と実際のVoiceOver読み上げはiPhoneの初期試験で確認する。合成GPSを使ったCLI/SQLite試験とは別に、端末の位置許可・ロック中の記録・共有先・電池を実機で確認する。
