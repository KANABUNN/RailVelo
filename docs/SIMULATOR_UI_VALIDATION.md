# Simulator UI検証 — v0.5

対象：iPhone 16 Simulator、同梱の合成GPSリプレイ。実GPSや個人アカウントは使用しない。XCUITestは実アプリ・Core Locationと共通の入力経路・推定・SQLite・CSV共有画面を使用する。

| 検証項目 | 方法 | 結果 |
| --- | --- | --- |
| 速度グラフの実描画 | 画面をスクロールし、グラフ領域の実画像内にデータ色の画素を確認 | CI実行待ち |
| 60秒・5分・全体 | 3ボタンを操作し、選択状態・観測件数・実描画を検査 | CI実行待ち |
| 記録開始・一時停止・再開・終了 | 実リプレイを操作し、非同期保存の完了を待つ | CI実行待ち |
| 履歴表示・保護・削除 | 一時停止中は削除不可、終了した今回作成の合成履歴だけ削除 | CI実行待ち |
| CSV | SQLiteから生成されたCSVのiOS共有画面を表示、送信せず閉じる | CI実行待ち |
| 明暗表示・大きい文字 | 実際のSimulator設定とAccessibility Audit | CI実行待ち |
| VoiceOver | 基本ラベルと説明は自動検査。音声・フォーカス移動は本人のiPhoneで確認 | 実際の読み上げは未実施 |

XCUITestの各操作画像は`ui-light.xcresult` / `ui-dark.xcresult`に保存する。公開できるのは、この使い捨てSimulator上の合成データによる検証成果物だけ。ユーザーが実機で記録したファイルはCIへ送らない。
