# Simulator UI検証 — v0.5

更新日: 2026-10-21。

対象：macos-26 arm64 / Xcode 26.6 / iOS 26.5 SDK・runtime / iPhone 16 Simulator、同梱の合成GPSリプレイ。実GPSや個人アカウントは使用しない。XCUITestは実アプリのReplayObservationSourceから、実GPSと共通の推定・SQLite・CSV経路を使用する。

下表は最終配布候補`afd55bb`のCIと実画像で確認した結果である。

| 検証項目 | 方法 | 結果 |
| --- | --- | --- |
| 速度グラフの実描画 | 画面をスクロールし、グラフ領域の実画像内にデータ色の画素を確認 | 点の画素検査・3期間の目視が成功。時刻目盛の重なり解消も確認 |
| 60秒・5分・全体 | 3ボタンを操作し、選択状態・観測件数・実描画を検査 | 3期間の切替・点描画は成功 |
| 記録開始・一時停止・再開・終了 | 実リプレイを操作し、非同期保存の完了を待つ | 一連の操作と永続化待機が成功 |
| 履歴表示・保護・削除 | 一時停止中は削除不可、終了した今回作成の合成履歴だけ削除 | 表示・保護・対象限定削除の操作が成功 |
| CSV | SQLiteから生成されたCSVのiOS共有画面を表示、送信せず閉じる | ネイティブ共有画面の表示とキャンセルが成功。実機での列・座標系・単位・全行の検査は別試験 |
| 明暗表示・大きい文字 | 実際のSimulator設定とAccessibility Audit | Light/Dark・拡大文字の指定監査とスクロールが成功 |
| VoiceOver | 基本ラベルと説明を自動検査。本人端末の音声・フォーカス移動は別途記録 | CIは実際の読み上げを検査していない。本人申告の基本確認は下記 |

自動監査はメイン画面の指定時点で実行し、LargeTextはhitRegion・sufficientElementDescription・textClipped・dynamicType、Darkは前3項目を対象とする。スクロール後のグラフは操作・画像でも確認する。この自動監査だけを、実際のVoiceOverによる音声・フォーカス移動や、全画面・全状態の網羅的な監査を済ませた証跡とは扱わない。

XCUITestの各操作画像は`ui-light.xcresult` / `ui-dark.xcresult`に保存し、直接参照できるPNGとmanifestを`ui-light-screenshots` / `ui-dark-screenshots`へ書き出す。公開できるのは、この使い捨てSimulator上の合成データによる検証成果物だけ。ユーザーが実機で記録したファイルはCIへ送らない。

## 合格へ拡張しない範囲

同梱fixtureの観測間隔は25秒で、連続観測として結ぶ閾値を超えるため、今回のグラフは点として描画される。点の実画素を確認した結果を、短い取得間隔での連続線・実GPSの測定値の妥当性・列車での実走の合格へ拡張しない。連続線は未確認で、VoiceOverの基本確認は下記の本人申告に分けて記録する。合成GPSを使ったCLI/SQLite試験と、下記の位置設定・約5分のロック試験・約8分の別アプリ試験の本人申告を分けて扱い、取得間隔・欠測・共有先・電池などの未確認項目は実機試験へ残す。

利用者の申告端末はiPhone 16 / iOS 27.0.1。TestFlight版RailVelo 0.5.0（500.7.1）の導入・起動に加え、前面実GPSの精度・静止/歩行速度の表示、グラフ表示、CSV保存、画面上のエラーがないことを本人申告で確認した（2026-10-21）。位置許可は「常に許可」・正確な位置情報オン。約5分のロック中の記録をグラフ上で確認でき、CSV保存と解除後の画面表示も問題なく、画面上のエラーなしとの追加申告を得た。端末の遠隔操作・直接観測は行っていない。

別アプリ試験では、約8分間別アプリを開いた後、グラフ上に不審な動きがなく、RailVeloの画面へ戻った後の速度変化とその他異常なしを本人申告で確認した。「再開」は画面へ戻る意味であり、一時停止・再開操作の確認ではない。当時の回答には履歴参照・CSV保存の個別結果がなく、後続の履歴・CSV試験と分けて記録する。

後続の案内（記録終了→履歴の日時・最高速度・グラフ確認→アプリスイッチャーから閉じて開き直す→同じ履歴内容を確認→保存CSVをFilesで開く）に対し、終了済み履歴の存在・内容の同一性、CSVを問題なく開けたこと、画面上エラーなしを本人申告で確認した。I05はこの表示・保持の範囲で合格。P01は観測件数・駅イベント・DB内部の比較がなく、P02は列単位・座標系・単位・全行の検査がないため、部分確認として残す。

同じbuildのリプレイ試験では、表示、一時停止・再開、60秒/5分/全体の3期間切替、スクロール、履歴の削除が正常で、画面上エラーなしと本人から報告された。直前の案内はリプレイ開始→一時停止・再開→3期間切替→終了→今回のテスト記録だけ削除し既存実GPS履歴の保持を確認する手順だったが、既存実GPS履歴が残ったという明示報告はない。I04・R02・R05・P05は操作の範囲で部分確認とし、二重開始・モード変更防止、時刻軸・選択範囲・数値精度、同梱fixture完走・全推定値、欠測線、誤削除防止までの合格にはしない。

明暗表示・文字拡大・VoiceOverの基本確認では、案内した3項目に対して本人から「確認事項すべて問題なかった．エラーもなし．」と回答された。ライト/ダークでの速度・状態・グラフ・主要ボタンの可読性、大きい文字での欠け・重なり・操作不能がないこと、VoiceOverでの速度・状態・主要ボタンの名前/値の読み上げと順移動を、I03の範囲で本人申告の合格として記録する。端末の直接観測はなく、具体文字サイズは未報告。全画面/全状態の網羅的監査や完全なアクセシビリティ適合を保証する結果ではない。初期受入の基本確認をまとめ、追加の短期確認は求めず、残る長時間・電池・実走などへ引き継ぐ。

約5分のロック試験と約8分の別アプリ試験はともに部分確認であり、10分以上の条件は未達。CSV取得間隔・欠測は未解析。別アプリから戻った後の速度変化は新規更新の基本的な根拠だが、精度・更新周期は未検証で、ロック解除後の新規GPS更新は別条件として未確認。ロック中のグラフ上の記録継続を、無欠測・連続線・新規GPS更新成功・CSV内容正常の証明にはしない。「その他異常なし」を、未回答の個別項目の全面合格にはしない。速度の数値・妥当性・測位までの秒数、実GPS側の3期間切替・連続線、実GPSでの一時停止・再開を含む全工程も未検証。最高速度は表示内容の保持までの確認で、測定値の妥当性は未検証。終了済み履歴の再起動後保持を、記録中の強制終了・OS終了復旧の成功には拡張しない。長時間・電池・列車での実走は未検証で、実走ログは取得していない。SimulatorのiOS 26.5での結果と分け、[実機試験計画](DEVICE_TEST_PLAN.md)に確認範囲と残る試験を記録する。
